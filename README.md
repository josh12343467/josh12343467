## 🚀 Featured Projects

### 1. ClassRoom Studio: Classroom Management App for Teachers

An offline-first web app for teachers with an interactive seating chart, attendance tracking, seat-based group generation, and a weighted gradebook that supports DepEd and college grading scales. Teachers can sign in with Google, and their classes sync across devices.

* **Live Demo:** [classroom-studio-jade.vercel.app](https://classroom-studio-jade.vercel.app). Choose *"Continue without an account"* to try it with sample data.
* **Source Code:** [github.com/josh12343467/classroom-studio](https://github.com/josh12343467/classroom-studio)
* **Tech:** Next.js · React · TypeScript · Supabase (Auth + Postgres with Row Level Security) · Zustand · Tailwind CSS · Vitest

### 2. Cirvia: IoT Smart Home Prototype

A scale-model smart home built on an Arduino Mega and controlled from a Flutter app by touch or voice over Bluetooth. It features RFID door access, fire and gas detection with emergency alerts, a roof that closes automatically when it rains, and a garage door with a car-safety interlock.

* **Source Code:** [github.com/josh12343467/cirvia](https://github.com/josh12343467/cirvia)
* **Tech:** Flutter · Dart · Arduino · C++ · Bluetooth (HC-05) · Sensors & servos
